# Пет-проект: Сервис кадровых заявок и личный кабинет сотрудника (HR-Portal)

## 📌 Описание проекта
Данный проект представляет собой техническую документацию и архитектуру системы автоматизации кадровых процессов 

Система предназначена для упрощения подачи кадровых заявок , их автоматического маршрутизирования и согласования, а также предоставления сотрудникам единого личного кабинета.

## 👤 Ролевая модель (RBAC)

| Роль | Ключевые возможности |
| :--- | :--- |
| **Сотрудник** | Просмотр личного профиля, создание заявок, отслеживание статуса собственных заявок. |
| **Руководитель** | Просмотр заявок подчиненных, согласование / отклонение заявок. |
| **HR / Кадровик** | Финальная обработка одобренных заявок, закрытие документов. |
| **Администратор** | Настройка процессов в админ-панели, управление конструктором полей и типов заявок. |

---

## 🛠 Архитектура и ключевые модули

1. **Личный кабинет**:
   * Отображение персональных данных сотрудника.
2. **Реестр и сервис заявок**:
   * Создание заявок с динамической формой полей.
   * Фильтрация, сортировка и пагинация списка заявок.
   * История изменений статусов и комментариев.
3. **Административная панель (Конструктор процессов)**:
   * Создание новых типов заявок.
   * Добавление динамических полей в форму (текст, дата, число, файл).
   * Настройка цепочки согласования (Workflow).
